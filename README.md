# CIC Personal Data Remover

CICの信用情報開示報告書を、Windows端末内でマスキングするツールです。指定した領域を黒塗りした画像PDFを新しく作ります。

## 動作と確認範囲

- ページ数・順序に制限はありません。
- 対応する帳票の氏名・生年月日・住所・電話番号・本人確認情報・照会入力欄などをマスキングします。
- 帳票として判定できないページは、そのページ全体を黒塗りして出力します。処理は続行しますが、そのページの内容は残りません。
- 元PDFは上書きしません。解析後に元ファイルの内容が変わった場合は再解析が必要です。
- 出力の文字層・添付・リンク・メタデータなどを検査します。画像内に残る個人情報の不存在を保証する検査ではありません。共有前に全ページを目視確認してください。

## 通信と保存

アプリにアップロード、テレメトリー、自動アップデート機能はありません。UNC、ネットワークドライブ、既知のクラウド同期ルート、再解析ポイント経由の入出力を拒否します。共有するPDFはローカルの通常フォルダで処理してください。すべての第三者バックアップ/同期ソフトを検出するものではありません。

入力のコピー、作業PNG、OCR本文をファイル保存しません。画像化・PDF検証はメモリ上で行い、検証済みPDFだけを排他的に作った一時ファイルへ書き、その後指定先へ置換します。通常の例外・中断時は自分で作った一時ファイルを後始末します。

単体EXEは実行用DLL等をOSの一時領域へ展開します。正常終了時には削除されますが、OSによる強制終了・停電等で残る場合があります。最終書き込み中の強制終了でも検証済みPDFの一時ファイルが残り得ます。物理的な完全消去、OSのページファイル、クラッシュダンプ、第三者ソフトの動作は保証範囲外です。

PyMuPDFの外部ログ/外部モジュール読込みに関わる環境変数は、アプリ起動時に無効にします。

検証内容と制限は [SECURITY.md](SECURITY.md) に記載しています。

## 開発と検証

Windows、Python 3.12系で検証しています。依存パッケージの取得は開発環境の準備時のみネットワークを使用します。

```powershell
python -m pip install -r requirements.txt
python work/app/cic_masker.py
python -m unittest work.app.test_cic_masker -v
```

テストは架空データから一時PDFを作成し、実際の個人情報や開示報告書に依存しません。

単体EXEの生成：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build.ps1
```

テスト用PDF、スクリーンショット、OCR本文、EXE、依存ライブラリはGitに含めません。

## ダウンロードとmacOS対応

Windows版の確認用EXEは [Releases](https://github.com/takacore/cic-personal-data-remover/releases) に置きます。Pythonの別途インストールは不要です。署名なしのため、Windowsが警告を表示する場合があります。ダウンロードしたファイルは同梱のSHA-256一覧で照合できます。

macOS版・DMGはまだ提供していません。移植と実機検証に協力いただける方向けの条件を [CONTRIBUTING.md](CONTRIBUTING.md) にまとめています。Windows版を拡張子だけ変えてDMGにすることはできません。リポジトリは現時点でPrivateの確認用です。
